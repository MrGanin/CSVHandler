# YouTube Metrics CLI

CLI tool для обработки CSV-файлов с метриками YouTube видео и генерации отчётов.

## Создание тестовых файлов CSV

```bash
python create_test_files.py

```

## Пример запуска

```bash
python main.py --files stats1.csv stats2.csv --report clickbait

```
